⚡ Pattern of the Day
Today is the runtime turn. Governance descends from the state's identity layer into the execution substrate — and the state moves into the power layer.

A day after a government defined who an agent is (Estonia's ID codes), NVIDIA + ServiceNow defined what every action it takes is allowed to do: Project Arc runs inside NVIDIA OpenShell, a sandboxed, policy-governed runtime, while ServiceNow AI Control Tower logs every file read, command executed and API called. Governance is becoming a property of the runtime itself, not just identity at the top of the stack.

In parallel the state pressed into the physical layer: FERC's 90-day fast-track order (18 Jun) means grid access is now actively arbitrated — running alongside the federal-oversight bill flagged yesterday, so power is regulated in two directions at once. Sovereignty widened from a cloud scheme into the full four-instrument EU package, all against an AI Act clock at ~39 days.

For Group The most consequential near-term call is to require policy-bound runtime execution + per-action audit as a baseline in Group's agent control-plane selection — governance has moved into the substrate — while keeping the full 2-August GPAI + Article 50 readiness programme funded.
