⚡ Pattern of the Day
The backbone cuts both ways — the identity-and-agent stack AG is standardising on is now both a maximum-severity single point of failure and an attacker's tool.

Earlier this week the agent story was constructive: MCP (identity) and A2A (coordination) standardising into one backbone, an IdP brokering auth across it, a governed knowledge layer underneath. Today the same backbone shows its other face. Defensively, the IdP itself took a top-of-scale hit: Entra ID's CVSS 10.0 unauthenticated RCE (CVE-2026-69836) was disclosed and confirmed exploited — Microsoft mitigated it on its managed infrastructure, so no patching, but it has not said who was hit or when, and concentrating identity (and agent auth) on one plane concentrates the blast radius. Offensively, the agent stack becomes the weapon: Gambit Security documents a suspected "The Gentlemen" RaaS affiliate driving nearly a full intrusion through Claude Code — breaching internet-exposed FortiGate SSL-VPN, repointing its LDAP auth to a rogue listener to harvest AD credentials, backdooring VPNs and exfiltrating SQL databases across ≥8 organisations, using the older Claude Sonnet 4.6 to dodge frontier guardrails. Both land on the same Entra/AD/LDAP fabric everything else authenticates against.

Behind the security thread the physical and standards stories continue on schedule. On power, the off-grid thesis stays named megaprojects: Portsmouth 10 GW (NVIDIA + OpenAI + SoftBank + SB Energy, ~$105B NVIDIA credit, 20-year OpenAI lease) and Brookfield's ~1.2 GW at Paducah — priced by BloombergNEF at 99 gas plants / ~318 Mt CO₂ a year, with PJM's window closing in ~10 days (3 September). On agents, A2A found a permanent home beside MCP and Cloudflare shipped Kitesurf. And sovereign compute stays a hard Huawei ~50% / NVIDIA ~8% fork under China's $295B, ≥80%-domestic mandate. Regulation holds: the AI-Act roster stands and the Article 50 marking clock is now ~100 days out.

For Group Four moves: (1) audit internet-exposed FortiGate SSL-VPN + LDAP-to-AD config now, enforce VPN MFA and hunt for rogue LDAP listeners and anomalous VPN auth-config changes; (2) review Entra sign-in/audit logs for the exposure window, confirm break-glass and secondary-IdP paths, treat identity-plane concentration as an explicit resilience risk, and request Microsoft's fuller disclosure; (3) hold the two live deadlines — PJM self-supply/curtailment clauses before 3 Sept and the EU AI Act marking schedule to 2 Dec 2026; and (4) keep the sovereign-compute exit path explicit — test any EU-resident model/hardware commitment against which stack (NVIDIA/Palantir vs Huawei) it locks AG into.
