⚡ Pattern of the Day
The patch window is now shorter than the triage window.

The genuinely new item this window is a WordPress core flaw (CVE-2026-87902, CVSS 9.2) whose first exploitation attempt was logged the same day its patch shipped — 22 Sept, 11:49 UTC, with 68 attempts by the 23rd. Added to CISA KEV on 25 Sept (deadline 28 Sept), it is the highest-reach item in weeks: WordPress is the most widely deployed component in any group's public web estate.

Two supply-chain signals sharpen the lesson. A dormant GitHub Actions compromise re-armed itself the moment two actions-cool repos came back online on 16 Sept with malicious tags never cleaned; and Cloudflare's cross-tenant Containers postmortem shows even a three-day fix leaves a multi-week residual-data cleanup tail. Meanwhile the KEV clocks land — WSO2 and Adobe Commerce today, SharePoint / WordPress / MikroTik tomorrow — every one due after a fix already existed.

For Group Confirm the WordPress fix across every brand and corporate site and hunt before 28 Sept; close WSO2 and Adobe Commerce today, SharePoint and MikroTik tomorrow; audit CI/CD for mutable third-party action tags and pin to commit SHAs; register the Cloudflare postmortem as a multi-tenancy assurance data point. Assume exploitation begins at disclosure, not at the deadline, and treat "fixed" as the start of verification. Standing items (EU AI Act 2 Dec marking ~66 days, CRA Art. 14, DC power/HBM, EU DMA) carry without a fresh trigger.

01
Security & Operational Resilience · new KEV entrant · deadline 28 Sept

Confirm the WordPress core fix for CVE-2026-87902 across every AG web property and hunt any reachable site

Suggested action · Verify every WordPress installation across AG's brand, corporate and marketing estate is updated to a fixed build — 7.1.2 / 7.0.6 / 6.9.9 / 6.8.10 or the matching backport to 4.7.37 — closing CVE-2026-87902 (unauthenticated path traversal in get_page_template() → local PHP inclusion, conditional RCE where a "page-" theme directory and a readable target such as pearcmd.php exist; affected 4.7.0–7.1.1, CVSS 9.2). Because exploitation began the same day the patch shipped, treat any internet-reachable WordPress as an active target and hunt for attacker-written PHP and pearcmd.php-style inclusion in web logs from 22 Sept onward. Consequence of inaction: WordPress is the most widely deployed component in AG's public web footprint; an unauthenticated flaw with conditional RCE on a customer-facing brand site is a foothold and a brand-and-data event, and the large install base makes uneven patching likely.

02
Security & Operational Resilience · deadline today

Close out WSO2 API Manager CVE-2026-5430 and Adobe Commerce / Magento CVE-2026-71362 by today's 27 September deadline

Suggested action · Confirm the fix for CVE-2026-5430 (WSO2 JWT-signature bypass → forged admin token, CVSS 9.8; fixed April 2026, exploited since 13 Sept) on every WSO2 API Manager / API Control Plane / Traffic Manager / Universal Gateway instance, and the isolated fix Adobe shipped on 8 Sept for CVE-2026-71362 (incorrect authorization / session-binding, CVSS 9.1, unauthenticated account takeover) on any Adobe Commerce (2.4.4–2.4.9) / Magento Open Source (2.4.6–2.4.9) storefront. Hunt for forged-token / anomalous-admin activity and anomalous storefront session switching on anything internet-reachable and unpatched. Consequence of inaction: a forged signature hands an unauthenticated attacker administrator control of the API gateway; the Adobe flaw hijacks shopper sessions — a data-protection and brand event. A version string is not proof of no prior compromise.

A pre-authentication SQL injection (CVSS 8.1) in the virtuser_query plugin via a preg_replace() backslash-escape bypass, exposing mail credentials and stored messages; fixed in Roundcube 1.6.16 / 1.7.1 (May 2026), with the Canadian Centre for Cyber Security confirming in-the-wild exploitation. Next trigger: KEV addition, a mass-scan campaign, or Roundcube found in AG's mail estate.
Frontier-AI self-regulatory standards body. Google / OpenAI / Anthropic's proposed standards authority carries without new state; it would set incident-reporting norms, third-party model testing and auditor qualifications. Next trigger: a formal launch, a published incident-reporting format, or a government body endorsing or contesting it.

Offensive AI-agent campaigns and "agent-data-security" framing keep agent identity, tool scope and data boundaries on the agenda for AG's agent-control standard. Next trigger: a named enterprise victim of an AI-agent-driven intrusion, or a concrete agent-data-security obligation reaching AG markets.

Next trigger: a concrete demand-response/interconnection deal, or a Turkish/EU grid operator adopting flexible-connection terms.
