⚡ Pattern of the Day
The security perimeter is being redrawn around AI — as both the thing to defend and the tool doing the defending — while the old appliance-edge fires still burn.

Two of today's three signals are about AI as attack surface and AI as defence. GitLab shipped critical patches for a flaw in the AI Gateway that bolts generative features onto its developer platform: insecure template expansion in the Duo Workflow Service lets an authenticated user run code on the gateway. At the same time Google began shipping Gemini 3.8 Flash Cyber to trusted defenders, pairing it with the CodeMender agent to find, validate and patch vulnerabilities autonomously — the same capability that compresses the window between disclosure and mass exploitation for everyone.

That window is already near-zero on the edge: FortiMail's unauthenticated file-write zero-day was KEV-listed the day it was disclosed and its US federal remediation deadline is tomorrow — alongside the still-open Cisco SD-WAN Manager, NetScaler and Apple CoreGraphics items. AI is changing who holds the advantage; it has not retired the pre-auth appliance problem.

For Group Today is the last day to close the FortiMail zero-day (CVE-2026-104286) before the 4 Oct federal deadline — inventory, pull the management interface off the internet, patch to 8.0.2 / 7.6.7 / 7.4.9, assume-compromise if reachable before patch. Validate whether any self-managed GitLab runs the AI Gateway / Duo and patch to 19.4.1 / 19.3.3 / 19.2.7. Treat AI features on internet-facing developer and collaboration platforms as first-class attack surface in architecture review, and begin evaluating AI-assisted vulnerability management as the disclosure→exploitation window keeps shrinking. Hold the carried edge wall (Cisco SD-WAN Manager, NetScaler, Apple, lapsed-KEV backlog). Standing: Micron/Broadcom AI-compute lock-ins; EU AI Act Art. 50 marking due 2 Dec 2026 (~60 days); CRA Art. 14 in force; NIS2/DORA autumn convergence.

Finish inventory, isolation and patching of FortiMail against the actively-exploited zero-day CVE-2026-104286 — today is the last clean window

Suggested action · Inventory every FortiMail appliance, prioritising any with its administrative/management interface reachable from the internet. Apply Fortinet's mitigations now — disable access to the management interface from the internet or restrict it to a trusted private network, and disable Identity-Based Encryption (IBE) support via the CLI — and upgrade immediately to a fixed release: 8.0.2 or later, 7.6.7 or later, or 7.4.9 or later (the 7.2 branch must migrate to 7.4+). Because the flaw gives an unauthenticated attacker arbitrary file write and code execution, hunt any appliance that was internet-reachable before patching for unexpected files, web shells and config changes, and treat it as potentially compromised. Consequence of inaction: an unauthenticated attacker writes files and runs code on the email-security gateway — a device in the trust path for all inbound/outbound mail — a foothold for mail interception, credential capture and onward intrusion; after the 4 Oct deadline lapses, treat any still-exposed appliance as assume-compromise, not a patch window.
Owner: Messaging / Email Security Gateway + Network Edge + SecOps (Threat Hunt)By when: today (KEV 1 Oct; active exploitation; federal deadline 4 Oct)

📡 Radar — early & longer-horizon signals
Cohere ships Embed 5 with Pro and Fast tiers for enterprise AI (1 Oct). A new enterprise embedding model from a non-hyperscaler vendor — relevant as a building block for retrieval and agentic workloads where Group wants a model supplier outside the three US hyperscalers, and a data point for the sovereign-AI option set. Next trigger: enterprise benchmarks, EU-region / on-prem deployment options, or Group retrieval/RAG workloads reaching a model-selection decision.
Apple CoreGraphics zero-day CVE-2026-86950 stays on the patch list (no new state). Out-of-bounds write → arbitrary code execution on a crafted file (CVSS 8.8), patched 28 Sept (macOS 26.7.1 / 15.8.1, iOS/iPadOS) and added to CISA KEV 29 Sept; exploited in a targeted attack. The standing action is to patch executive and high-risk devices first. Next trigger: a broader non-targeted campaign, a public exploit, or the flaw appearing in commodity spyware.
AI-compute is now being locked in multi-year and vendor-financed — carried as a standing TCO watchpoint. Micron's ~$100B of take-or-pay hyperscaler memory contracts through 2030 (shortages guided to end-2027) and Broadcom's disclosed offer to lend Anthropic up to $42B to lease chips (both Issue #81) hold with no new state — a hardening of Group's on-prem AI TCO and vendor-concentration assumptions. Next trigger: a further HBM4 yield/ramp or DRAM spot move, another vendor-financed compute megadeal, or a credit signal from a key Group infra vendor.
EU AI Act Article 50 marking for pre-existing generative AI is ~60 days out (2 December 2026). GPAI enforcement is live and CRA Article 14 reporting has been in force since 11 September; only the calendar advanced this window. Next trigger: first formal GPAI enforcement action, or Commission guidance on Art. 50 marking formats.
EU DMA cloud gatekeeper decision for AWS + Azure due by November; NIS2 / DORA autumn convergence nears. The Commission's preliminary designation of AWS and Azure moves toward a final decision by November (interoperability / data-portability obligations would follow), while autumn 2026 is the point national NIS2 registration, supervisory readiness and management-body liability stop tolerating “still implementing,” alongside live DORA enforcement — both bear on Group's EU cloud-sourcing and in-scope entities. Next trigger: the final gatekeeper designation, published obligations, or a first national NIS2/DORA supervisory action.
