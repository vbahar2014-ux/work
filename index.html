⚡ Pattern of the Day
The vendor's severity label is not the clock — the exploited-vulnerability catalogue is.

A deliberately short, security-led edition. The window's one genuinely new item is a Microsoft SharePoint Server flaw (CVE-2026-65660) that Microsoft first published as low-severity spoofing and that turned out to be authenticated remote code execution — added to CISA's KEV catalogue on 25 Sept with a 28 Sept deadline, even though the fix shipped back on the 11 August Patch Tuesday.

The rest is timing, not novelty: the Check Point / Arista / F5 cluster deadline lapsed on 25 Sept; WSO2 and Adobe Commerce fall due tomorrow. In every case the exploitation catalogue — not the vendor advisory or the CVSS label — set the real remediation clock, and it ran ahead of the patch cadence.

For Group Confirm the SharePoint August fix is actually deployed and hunt any reachable SharePoint before 28 Sept; close WSO2 and Adobe Commerce by tomorrow; treat the lapsed Check Point / Arista / F5 cluster and last week's backlog as breach hypotheses on anything reachable and unpatched. Reconcile the estate against the KEV catalogue rather than vendor severity; verify fixed builds rather than trust version or severity strings. Standing items (EU AI Act 2 Dec marking ~67 days, CRA Art. 14, the DC power/HBM theme, EU DMA) carry without a fresh trigger.

4 decisions · assign owner & date
01
Security & Operational Resilience · new KEV entrant · deadline 28 Sept

Confirm the Microsoft SharePoint fix for CVE-2026-65660 is deployed and hunt any reachable SharePoint estate

Suggested action · Verify every on-prem SharePoint Server 2016 / 2019 / Subscription Edition instance carries the 11 August 2026 security update fixing CVE-2026-65660 (code injection via SafeControls filtering → authenticated low-privileged RCE, CVSS 8.8). Because Microsoft first published this as low-severity "spoofing" and only its reclassification to RCE + the 25 Sept KEV addition make it a deadline item, treat "patched in August" as unproven until confirmed per instance, and hunt for post-exploitation on any SharePoint reachable from untrusted networks. SharePoint Online is not affected. Consequence of inaction: SharePoint is a high-value internal collaboration and content store, a low-privileged account (which many users hold) can reach code execution on the server, and the "spoofing" label means the August patch may have been deprioritised.
Owner: Collaboration / SharePoint Platform + SecOps (Threat Hunt)By when: 28 September (CISA KEV federal deadline)
02
Security & Operational Resilience · deadline tomorrow

Close out WSO2 API Manager CVE-2026-5430 by tomorrow's 27 September KEV deadline

Suggested action · Confirm the fix for CVE-2026-5430 (JWT-signature bypass → forged admin token, CVSS 9.8; fixed April 2026) on every WSO2 API Manager, API Control Plane, Traffic Manager and Universal Gateway instance, and hunt for forged-token / anomalous-admin activity where anything was internet-reachable and unpatched. Consequence of inaction: a forged signature hands an unauthenticated attacker administrator control of the API gateway; a patched version string is not proof of no prior compromise, so the hunt is as load-bearing as the patch.
Owner: API Platform / Integration + SecOps (Threat Hunt)By when: 27 September (tomorrow)
03
Security & Operational Resilience · deadline tomorrow

Close out Adobe Commerce / Magento CVE-2026-71362 by tomorrow's 27 September KEV deadline

Suggested action · Where any AG entity runs Adobe Commerce (2.4.4–2.4.9) or Magento Open Source (2.4.6–2.4.9), confirm the isolated fix Adobe shipped on 8 Sept for CVE-2026-71362 (incorrect authorization / session-binding failure, CVSS 9.1, unauthenticated account takeover) and review storefront logs for anomalous session switching. Consequence of inaction: any customer-facing storefront is directly exposed — unauthenticated shopper-session hijack and account takeover, a data-protection and brand event across AG's consumer channels.
Owner: E-commerce / Digital Platform + Web Application Security + SecOpsBy when: 27 September (tomorrow)

📡 Radar — early & longer-horizon signals
MikroTik RouterOS CVE-2026-67279 added to KEV (deadline 28 Sept). SSH-protocol behavioural-workflow bypass (CVSS 6.9) letting an unauthenticated attacker open a session channel and run commands; exploited since 2 Sept. Lower AG relevance than enterprise edge gear, but validate whether any RouterOS sits in AG's edge or branch estate. Next trigger: RouterOS found in inventory, or IoCs matching AG telemetry.
Frontier-AI self-regulatory standards body. Google / OpenAI / Anthropic's proposed standards authority (surfaced ~24 Sept) carries without new state; it would set incident-reporting norms, third-party model testing and auditor qualifications. Next trigger: a formal launch, a published incident-reporting format, or a government body endorsing or contesting it.
Agentic-AI misuse as an operational problem. Offensive AI-agent campaigns and "90-day" agent-data-security framing keep agent identity, tool scope and data boundaries on the agenda for AG's agent-control standard. Next trigger: a named enterprise victim of an AI-agent-driven intrusion, or a concrete agent-data-security obligation reaching AG markets.
Power stays the binding data-centre constraint. The AI Energy Management Alliance and HBM supercycle keep capacity gated on grid-flexibility and thermal design, not space. Next trigger: a concrete demand-response/interconnection deal, or a Turkish/EU grid operator adopting flexible-connection terms.
EU DMA cloud gatekeeper decision looms. The Commission's preliminary designation of AWS and Azure moves toward a final decision due by November; interoperability and data-portability obligations would follow. Next trigger: the final designation decision, or published gatekeeper obligations.
