⚡ Pattern of the Day
From the appliance to the forged token, the trust fabric is the attack surface.

Issue #72, covering the ~24 hours since Issue #71 — a quiet window with two clocks running down and one new entrant. Cisco's quiet addition of an iACL interim mitigation to the Identity Services Engine advisory (CVE-2026-76460, CVSS 10.0, deadline tomorrow) is an admission dressed as guidance: with no full fix beyond patching, the only other defence is to stop the management API from being reachable at all — an authentication plane you can only protect by hiding it.

Hours later, watchTowr's honeypots confirmed attackers forging administrator JWTs against exposed WSO2 API Manager instances (CVE-2026-5430, CVSS 9.8), defeating signature verification to mint admin access on an enterprise API gateway patched five months ago. Different vendors, same weakness: the mechanism that decides who is trusted — an ISE API endpoint, a JWT signature check — is what attackers defeat, and in both the fix has existed for a while, but exposure predating it is what pays.

Assume the trust layer is reachable until proven otherwise; verify, don't trust version strings. Security & Operational Resilience · deadline tomorrow

Patch Cisco Identity Services Engine to a fixed release before 19 Sept (CVE-2026-76460, CVSS 10.0); apply the new iACL interim mitigation now where the upgrade can't complete in time

Suggested action · Upgrade ISE / ISE-PIC to a fixed patch level (3.5 P4, 3.4 P7, 3.3 P12, 3.2 P11, 3.1 P12) before 19 Sept; where an upgrade cannot finish by the deadline, apply Cisco's interim infrastructure ACL (iACL) guidance to permit only required management- and control-plane traffic to the appliance, then patch. Because the flaw was found in the wild and lets an attacker run commands as root and delete indicators of compromise, treat any internet-reachable or unpatched ISE as suspect and hunt for post-exploitation (rogue admin accounts, altered logs, outbound connections). Consequence of inaction: ISE is the network-access-control and identity-policy plane — root on it lets an attacker mint access, disable enforcement and erase their tracks, a compromise patching alone will not remediate once exposure predates the fix.
