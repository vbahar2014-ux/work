⚡ Pattern of the Day
Yesterday the agent control plane got an open spec. Today the hyperscalers ship competing platforms — and "which control plane?" becomes the decision.

The platform war's centre of gravity moves decisively off the model and onto the agent control plane. Google Cloud Next '26 answers Microsoft's open ACS spec with a full proprietary stack — the Gemini Enterprise Agent Platform (Agent Studio, A2A orchestration, and crucially an Agent Registry, Agent Identity and Agent Gateway), 8th-gen TPUs, and an Agentic Data Cloud that turns the data layer into agent-grade fabric. ServiceNow ships Autonomous Security & Risk as the framework-agnostic governance layer over everyone's agents.

So the most consequential near-term call is no longer "which model" but which agent control plane — registry, identity, audit, lock-in — and there are now at least three serious, mutually incompatible answers. On the floor, yesterday's power crisis converts into a federal remedy (FERC's ~90-day interconnection fast-lane), while the EU's marking Code opens for signing with the clock at ~36 days.

For Group The durable edge is a portable governance and identity standard, not a vendor's frontier weights. Pick Group's agent control-plane + identity standard deliberately before the next production rollout — at scale, that choice sets the identity, audit and lock-in model.
