⚡ Pattern of the Day
Yesterday the model gate lifted and the physical gate came down. Today the story moves one layer in each direction — the agentic layer grows rails, the compute layer gets a new price-setter.

Above the model, autonomy now ships with governance attached: NVIDIA + ServiceNow's Project Arc runs every action inside a sandboxed, policy-governed runtime (OpenShell) under a control tower that logs files, commands and API calls, and SnapLogic MCP Builder (GA) turns AG's integration estate into governed, identity-propagating MCP tools — the concrete shape of the control-plane thesis AG has been building toward.

Below the model, Meta Compute prepares to rent hyperscaler-scale GPU capacity (600k+ H100-equivalents) at a targeted ≥20% discount to AWS/Azure — a second argument in two days, after Claude Sonnet 5, for keeping AG's sourcing portable. And the physical build-out hardens past fiscal/political friction to the grid itself: 4–7-year interconnect queues and utilities now openly discounting speculative demand.

For Group Benchmark the new governed agent runtimes (OpenShell / AI Control Tower) and MCP plumbing against AG's own model-agnostic control-plane requirements — and treat firm, contracted power on multi-year timelines as the base case for any 2027–2030 capacity. One deadline still lands this cycle: the EU AI Act content-transparency Code decision by 22 July.
